# SQL Data Extraction and Analysis

## Project Overview
This project demonstrates how to extract, store, and analyze sales data using SQLite, Python, Pandas, and SQL. The dataset is imported into a SQLite database, and business insights are generated using SQL queries.

## Tools Used
- Python
- SQLite
- Pandas
- Jupyter Notebook
- VS Code
